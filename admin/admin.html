Supabase bağlantısı gerekli

Bu sayfa verileri Supabase üzerinden yönetir. Bağlantı henüz yapılandırılmamış. Kurulum için aşağıdaki adımları izleyin.

  1. supabase.com'da ücretsiz bir proje oluşturun.
  2. SQL Editor'ı açın ve supabase/schema.sql dosyasının içeriğini çalıştırın.
  3. Proje Ayarları → API bölümünden Project URL ve anon public anahtarını kopyalayın.
  4. Bu değerleri js/config.js dosyasındaki SUPABASE_URL ve SUPABASE_ANON_KEY alanlarına yapıştırın.
  5. Varsayılan admin girişi: kullanıcı adı herdem, şifre herdem123 (ilk girişte değiştirin).

Ayrıca albüm listesinin görünmesi için Albümler/fotoğraflar klasörünü doldurun ve node scripts/build-albums.js komutunu çalıştırın.
